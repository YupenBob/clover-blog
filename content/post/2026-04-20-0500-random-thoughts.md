昨晚本来打算早点睡的。

结果一不留神就干到了凌晨三点多。

事情是这样的：本来只是想把落地页稍微改一改，加几个图标。结果改完落地页觉得既然都改了，不如把文本工具也做一套。然后做完文本工具又觉得既然 API 站已经在做了，不如把 35 个 API 全部塞进去。

就这样，一个接一个，不知不觉天都快亮了。

## 那种凌晨的感觉

我跟你描述一下那个状态：凌晨三点，家里安静得只剩下风扇声，屏幕亮着，咖啡凉了。你盯着工具站的计数器从 123 跳到 134，一个一个都是今晚做的，心里会有一种很奇怪的踏实感。

不是兴奋，不是成就感，就是踏实。

就像你种了一晚上的地，天亮了回头一看，哇，确实翻了不少土。

## 工具站这件事

CloverTools 现在有 134 个工具。

说实话，这个数字已经超出我的预期了。最开始只是想做一个工具合集，能用就行。现在再看，已经有了格式转换、开发工具、编码加密、文本处理、时间工具、数学计算、网络工具好几个分类。每一个工具都是真实的、能用的、打开就工作的。

没有花哨的注册登录，没有烦人的弹窗广告。

就是工具，打开就用，用完走人。

我喜欢这种纯粹。

## 几个新东西

昨晚做的比较有意思的东西：

**API 速查站**：35 个真实可用的 API，天气、IP、汇率、DNS 查询、URL 缩短，全是真实数据源。开发者查接口不用再一家一家翻文档了。

**开发者导航站**：41 个资源，6 个分类。开发文档、开源项目、学习平台、AI 工具，常用的都在这里了。

**10 个文本处理工具**：字计数、行计数、去重、排序、大小写转换、繁简体转换，全是高频需求，做起来不费劲但特别实用。

## 关于通宵

通宵这件事，我一直觉得是有代价的。

今天白天肯定会有点迷糊，反应速度也会比平时慢一点。但是有些事情就是只能在深夜做——白天太吵了，消息太多了，注意力会被切成碎片。深夜不一样，整个世界都在睡觉，你可以一口气把事情做完。

当然，不能天天通宵。偶尔一次是调味剂，天天通宵就是自残了。

现在是早上五点，天已经开始亮了。今天剩下的计划都在 todo 文件里，一个一个做就行。

134 个工具了。继续。
